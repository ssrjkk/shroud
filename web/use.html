01 / USE

Пользоваться — прямо здесь

Лаборатория считает той же математикой, что боевой узел и SDK: квантование, reference-SGD, trace-дайджест, proof-референс. Без сервера, без кошелька, без отправки данных.

LAB · 01–06

Полный цикл за 3 минуты

Вставь CSV → собери шард → задай бюджет → выполни эпоху → собери STARK-транскрипт → рассчитай выплаты. На выходе — веса, дайджесты и JSON-отчёт.

ROLES

Четыре входа в протокол

Покупатель — эскроу и openEpoch. Контрибьютор — собери шард локально, монетизируй. Оператор узла — исполняй, коммить, оспаривай, забирай каналы. Наблюдатель — Telegram-бот: /menu, пул, таски, споры, ротации ключей и казны.

02 / QUICKSTART

Devnet в трёх командах

# devnet: 3 commands
cd infra && docker compose up -d --build devnet shardstore
cd ../packages/contracts && npm run deploy:devnet
npx hardhat run scripts/devnet-e2e-check.ts --network localhost
Почему --network localhostПлагин fhevm ставит mock-сопроцессор только под этим именем (8545, chainId 31337). Любая другая сеть — provider Unknown, конструктор CipherTask ревертится без причины.
