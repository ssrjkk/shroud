SEC / STATUS

Что enforced. И что нет.

Протокол двигает деньги. Зелёная таблица без красного стоила бы ничего — поэтому провалы лежат здесь с тем же кеглем, что победы. Решаешь, доверять ли ценность, — читай красный раздел первым. Полный разбор: docs/04-threat-model.md (62 находок) и docs/05-honest-limitations.md.

СтатусКод двигает средства и не проходил внешнего аудита. Не использовать с реальной ценностью. Актуальные числа прогонов — в CI. «Протестировано» ≠ «аудировано».

18 — enforced и покрыто

Учёт эскроу, реентрантность, пулы, abort, таргет споров, commit-reveal, оплата ре-экзекьюторов, порог раскрытия, key-pin в SDK (fail-closed), запрет cleartext по умолчанию, hostile-DA, ротации без перезаписи, fee-tokens fail-closed, сегментированный путь.

3 — задокументировано, не реализовано

Devnet-нюансы, часть экономики (взвешенное назначение ре-экзекьюторов), настоящий STARK-прувер — описаны как отсутствие, а не как механизм.

4 — известные пробелы

Sybil-кворум (плоские 3), бонд взносов opt-in без fraud-proof, полная STARK-проверка, подмена ключа внутри эпохи (ловится только на старте). Ниже — каждый с последствиями.

Что это значит для тебя

  • Не клади реальные деньги — аудита не было.
  • Зелёное — проверено тестами, красное — известные дыры.
  • Главный риск: сговор трёх адресов может сжечь награду узла.

03 / KNOWN

Известные нюансы

НюансСуть
Devnet и пиновый плагинhardhat run без моков ревертит конструктор без причины; deploy.ts печатает диагноз вместо голого реверта. Сьюта контракты покрывает полностью.
Сегментированные пруфыПуть достижим (commitEpochSegmented → verifyProofSegmented, покрыт тестом), но прувера в репо нет — проверяется мок по форме, не AIR.
Незрелые каналы ждут окноФинальная страница settle ждёт созревания каналов (ChannelsImmature) — комитет и refund приходят до +7 дней после последней эпохи. Контрибьюторы платятся раньше, из замороженного пула.
Зависимости-аудитыnpm audit ругается на транзитивы Hardhat 2 — это раннер тестов, не байткод. Фикс — мажор Hardhat 2→3 после релиза fhevm-плагина.
Сообщить об уязвимостиПриватно через GitHub Security Advisories: github.com/ssrjkk/shroud/security/advisories/new. Не открывай публичный issue, не прикладывай ключи и креды. Подтверждение — в течение 3 рабочих дней. В скоупе: логика CipherTask/PaymentVault/DecryptionGate/NetworkParams/ProofVerifier, криптомисюз, утечки секретов. Вне скоупа: задокументированные ограничения FHE/STARK, операторские single-ключи, фичреквесты.
