DOC / SHR-2026-01

Протокол целиком

Один абзац: пользователь шифрует запись на своём устройстве сетевым FHE-ключом и публикует только шифротекст. Покупатель кладёт бюджет в USDC и публикует спек модели. Любой узел может выполнить обучение по шифротекстам — арифметика FHE даёт шифротексты. Узлы коммитят каждую эпоху в ZK proof-of-compute; по принятии эскроу стримится контрибьюторам и узлам. Веса покупатель получает через пороговый комитет и только после settlement. Отдельные записи не расшифровываются никем и никогда.

Три инвариантаINV-1: plaintext виден только владельцу; в открытую выходит лишь выход модели и лишь после TaskSettled. INV-2: секрет FHE-ключа никогда не собран в одной памяти — Шамир t-of-n, n ≥ 3t−1. INV-3: врать узлу невыгодно — либо STARK сошёлся на настоящих дайджестах, либо fraud-окно и слэш большинством.

Коротко своими словами

Чужие таблицы учат твою модель, не показывая тебе ни одной строки. Деньги лежат в сейфе-контракте и раздаются только за проверенную работу. Ниже — детали для любопытных, в лаборатории — всё руками.

Иерархия ключей

s_pub публикуется в params-бандле и пинится в NetworkParams (защита от подмены). committeePub — BLS-агрегат для reveal без транзакции на члена. nodeId = keccak(blsPubKey[0:20] ‖ operator) связывает узел со стейком.

LAYOUT

Правило раскладки

В цепочке — обязательства и зашифрованное состояние; bulk-шифротекст — в DA. STARK проверяется по ончейн-ctRoot, поэтому fhEVM-нагрузка ограничена, а проверяемость сохранена.

03 / MATH

FHE-выбор и математика выплат

ВопросРешение
СхемаTFHE (tfhe-rs / Zama fhEVM) — программируемый бутстреп для глубоких конвейеров
Лейныeuint32: табличные данные и веса без взрыва шума CKKS

SETTLE

Деление бюджета B, эпох E

contributorPool = B·8000/10000; nodePool = B·1500/10000; treasury = остаток. contributor_i = pool · w_i / Σw, где w_i = sqrt(rows_i)·liveness — sqrt душит китов, liveness штрафует опоздавших. node_n = nodePool / (E·q) поровну по валидным коммитам. Остатки от деления — участнику с наибольшим address (детерминировано).

06 / RUN

Запуск и роли

Покупатель

fund a task
Эскроу: createTask(budget, params) → sealTask → openEpoch на каждую эпоху → requestReveal и withdraw. Пример: packages/contracts/scripts/devnet-e2e-check.ts.

Контрибьютор

sell value, not data
Шифруй локально: sdk.uploadAndMonetize(data, taskId, { features }). В проде — @shroud/sdk/relayer. Механику попробуй в лаборатории.

docker compose up -d node-a (ручки — infra/README.md §3) или собери node/. Узел регистрируется, исполняет, коммитит, спорит и забирает каналы.
